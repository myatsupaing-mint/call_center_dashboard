# PwC Job Simulation: Call Center Dashboard 📞  

This repository contains the work completed as part of the **PwC Job Simulation on Forage**, focusing on analyzing and visualizing call center performance data. Using Power BI, a comprehensive dashboard was created to provide actionable insights into key call center metrics, helping improve operational efficiency and customer satisfaction.  

## 📌 Project Overview  
The objective of this task was to analyze call center data and create a dashboard that:  
1. Highlights key performance metrics such as **total calls answered, abandoned calls, and resolution rates**.  
2. Visualizes trends in agent performance, satisfaction ratings, and average speed of answer.  
3. Provides insights into unresolved cases and identifies opportunities for improvement.  

## 🔍 Key Insights  
### Metrics Visualized:  
- **Total Calls Answered**: 4,054  
- **Total Abandoned Calls**: 946  
- **Total Resolved Cases**: 3,646  
- **Total Unresolved Cases**: 408  
- **Agent Performance**:  
  - Average talk duration and satisfaction ratings analyzed by topic (e.g., Admin Support, Contract-related, Technical Support).  
  - Top-performing agents identified through comparative analysis of satisfaction scores.  

### Key Findings:  
1. **Technical Support**: Higher average talk durations indicate complex queries but moderate satisfaction ratings highlight room for improvement.  
2. **Payment-related Issues**: Lower satisfaction ratings suggest further investigation into process bottlenecks.  
3. **Agent Performance**: Agents like Martha and Dan consistently achieved higher satisfaction scores across topics.  
4. **Abandoned Calls**: Strategies needed to minimize abandoned calls to improve overall customer satisfaction.  

## 💡 Technologies Used  
- **Data Visualization Tool**: Power BI  
- **Data Source**: Simulated call center dataset  
- **Key Skills**:  
  - Data Cleaning and Transformation  
  - Dashboard Creation  
  - Visual Analytics and Insights  

## 🛠 Dashboard Features  
- **Interactive Visualizations**:  
  - Bar charts, heatmaps, and KPIs for quick insights.  
- **Agent-wise Performance**: Satisfaction ratings and average talk durations by topic.  
- **Topic-specific Analysis**: Satisfaction ratings and speed of answer visualized across different query topics.
